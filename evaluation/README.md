# Evaluation tools

Эта папка предназначена для **оценки качества**, а не для пользовательского интерфейса.

Ручная разметка допустима здесь только как независимый `ground truth`, с которым сравнивается автоматический результат (`events.csv`, треки, идентификация). Она не должна использоваться для получения итогового результата программы.

Для событий используйте `scripts/evaluate_events.py`; план эксперимента описан в `docs/VALIDATION.md`.
